# hi-reader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a GitHub Pages–ready bookshelf + reader SPA supporting PDF/TXT/EPUB, local uploads, annotations, and WeChat-Reading–inspired UI.

**Architecture:** Vite + React SPA. Sample books from `public/books.json`; user books/progress/annotations in IndexedDB. Format adapters (`txt` / `epub` / `pdf`) share a `BookSession` API. Shelf at `/`, reader at `/read/:id`.

**Tech Stack:** Vite 6, React 19, React Router 7, TypeScript, Tailwind CSS v4, Vitest, `pdfjs-dist`, `epubjs`, `@phosphor-icons/react`, Motion (light hover only), GitHub Actions → `gh-pages`.

## Global Constraints

- Vite `base` default `/hi-reader/` (override with `BASE_PATH` env)
- Formats: `.pdf`, `.txt`, `.epub` only
- Annotations: TXT/EPUB range highlight + notes; PDF page bookmark/note only (no selection highlight)
- No backend; no accounts
- taste-skill dials: VARIANCE 5 / MOTION 3 / DENSITY 3; white shelf; reader themes light/sepia/dark
- Angular commit subjects: `type(scope): summary`
- New/changed logic: add/update Vitest unit tests
- Comments in English; user-facing UI copy may be Chinese to match reference

```ts
export async function loadCatalog(): Promise<BookMeta[]> {
  const res = await fetch(`${import.meta.env.BASE_URL}books.json`)
  const samples = (await res.json()) as BookMeta[]
  const local = await booksStore.listLocal()
  return [...samples, ...local]
}

export function filterByTitle(books: BookMeta[], q: string): BookMeta[] {
  const s = q.trim().toLowerCase()
  if (!s) return books
  return books.filter((b) => b.title.toLowerCase().includes(s))
}
```
